# MEM Observatory

Автономная RU/EN обсерватория токена Not Meme (MEM).

Контракт: `EQAWpz2_G0NKxlG2VvgFbgZGPt8Y1qe0cGj-4Yw5BfmYR5iF`. Точность: 9 знаков.

Основа: Freebielife/ARBUZ, коммит 002e564f61bb1e1edc37dcbc1599f630c7dadf31.
Флаг проекта предоставлен пользователем; оригиналы в assets/project.

## Возможности

- Покупки, продажи и подтверждённые сжигания; рейтинги и сервисные кошельки.
- Прямые MEM/TON сделки трёх проверенных пулов DeDust и STON.fi.
- График капитализации по цене основного DeDust пула × текущее предложение.
- Остальные пары показываются как карточки ликвидности.
- Общие метки OG, +888, четырёхзначных TON DNS и сжигания.
- История постепенно расширяется до 366 дней с сохранением курсоров.
- Снимок встроен в index.html; страница работает без внешних стилей, шрифтов,
  картинок и библиотек. Сеть нужна для обновления данных и поиска кошелька.

## Обновления и публикация

GitHub Actions: .github/workflows/update.yml, резервный cron :20/:50 UTC.
GitHub может задерживать плановые запуски. Для общего Cloudflare runner
потребуется доступ его GitHub токена к Freebielife/NOT-MEME.
Готовый index.html загружается в Resistance Tools; каждые 5 минут он проверяет
новый снимок в этом репозитории. Публикация TON Site отдельно не выполнена.
При ошибке источника сохраняются ранее подтверждённые данные.
Отсутствующие сведения не подменяются нулями.

## Проверка сумм DeDust

Количество TON для сделок DeDust берётся из успешного сообщения dedust_swap
самого пула. Поле ton_out агрегатора может включать возврат газа.
На проверенном примере продажи 2 MEM агрегатор указал 0.274111927 TON,
а исполненный обмен в сообщении пула — 0.000112375 TON.
Для графика используется количество токенов в обмене пула (poolTokenAmount),
так как оно может отличаться от полученного кошельком количества из-за комиссии токена.
